# สมุดบันทึกสวน · ขุนช่างเคี่ยน

เว็บภาษาไทยสำหรับบันทึกนก พรรณไม้ และกาแฟในสวนใต้ร่มไม้ขนาด 1–2 ไร่ ออกแบบจากแบบที่ 1 โทนครีม–เขียว

## การใช้งาน

- บันทึกวันที่ เวลา จุดสำรวจ ระยะเวลา ชนิดและพฤติกรรมนก พรรณไม้ สภาพกาแฟ อากาศ สภาพแวดล้อม และภาพถ่าย
- แยกข้อสังเกต การคาดเดา และสิ่งที่ควรสำรวจเพิ่มเติม
- ภารกิจรายสัปดาห์พร้อมสถานะและการแก้ไข
- ตารางค้นหาและกรองตามวันที่ นก พรรณไม้ จุด ฤดูกาล และสถานะ
- สรุปจำนวนบันทึกรายเดือนและนก–พรรณไม้ที่บันทึกร่วมกัน โดยไม่ตีความเป็นเหตุและผลหรือแนวโน้มประชากร
- ส่งออก CSV และสำรอง/นำเข้า JSON พร้อมภาพ

ข้อมูลเก็บใน IndexedDB ของเบราว์เซอร์แต่ละเครื่อง **ยังไม่ซิงก์ข้ามเครื่อง** ควรสำรอง JSON เป็นระยะ ไม่มีข้อมูลสำรวจจำลอง ภาพวาดประกอบไม่ใช่หลักฐานภาคสนาม

## พัฒนา

```bash
cd garden-fieldbook
npm ci
npm run dev -- --host 0.0.0.0
npm run build
npm run test:sites
```

โฟลเดอร์นี้เป็นโครงการอิสระ ไม่เปลี่ยนหน้าเว็บร้านค้าหรือเส้นทางเผยแพร่ของ repository หลัก ผล build อยู่ใน `dist/client` และ Worker ใน `dist/server/index.js` สำหรับ Sites โครงสร้าง runtime มือถือคงตามแม่แบบเดิม

## สถานะตรวจสอบ

TypeScript/Vite build, runtime integrity และ Sites worker tests 4 รายการผ่านแล้ว แต่การตรวจด้วยเบราว์เซอร์และการเปรียบเทียบหน้าจอยังติดขัดจากระบบ preview upstream connection จึงยังไม่เผยแพร่หรือ merge งานนี้ ดู `design-qa.md` สำหรับข้อจำกัด ห้ามถือว่า build ผ่านเท่ากับตรวจการใช้งานจริงแล้ว
